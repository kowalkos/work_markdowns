# filtrowanie

### dla browserów faktur i paragonów

## SearchBox filtrowanie

Dla browsera są wymagane jakieś sety filtrów np dla paragonów jest wymagany nip lub jako grupa numer kasy oraz numer tranzakcji. Gdy zostają podane wymagane wartości filtrów browser automatycznie załaduje nam dane, w przeciwnym przypadku może wystąpić potrzeba naciśnięcia przycisku (Zastosuj Wybrane), który załaduje nam dane dla aktualnie ustawionych wartości filtrów.

Warto zauważyć, że gdy jest naciskany przycisk (Zastosuj Wybrane), ścieżka ładowania danych oraz filtrów jest inna niż w przypadku zmiany filtra z searchBoxa
